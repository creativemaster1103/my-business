# Video editing

Ad creative editing for Hoolest: turning Video Briefs into finished, correctly named cuts.

**No footage lives here.** `my-business` is a public repo. Raw clips and exports stay on the
shared drive. This folder holds the things that should be the same on every edit: export
specs, cut lists, and the scripts that build and check cuts. `.gitignore` blocks video and
audio files so a stray export can't get committed.

Run every command below from inside `video-editing/`.

## Where the work comes from

Each Video Brief in Notion (`HPT###`) is one concept with **four hooks, one body and one CTA**,
which makes four cuts per brief. The brief opens with the **File naming** table: one file name
per hook, generated by the naming sheet. Those names are the deliverable names, copied exactly.
Never retype them.

## Workflow

1. **Cut** the hooks, body and CTA in your editor (Premiere, CapCut, Resolve).
2. **Build the four cuts.** Either export them straight from your editor, or export the parts
   as separate clips and let `assemble.py` join each hook onto the shared body and CTA.
3. **Export to spec.** See [`specs/meta-export.md`](specs/meta-export.md): 1080 wide, H.264,
   AAC, with captions inside the safe zones.
4. **QC** before uploading: `python3 scripts/qc.py <export folder>`
5. **Upload** to the shared-drive folder named in the brief's *Folder name* row.

## Scripts

Both use only Python 3 and ffmpeg. There's nothing to `pip install`.

### `scripts/assemble.py` builds cuts from a cut list

Copy [`jobs/HPT085.example.csv`](jobs/HPT085.example.csv) to `jobs/HPT###.csv`, paste the four
file names from the brief, and list each cut's clips in order:

```
filename,hook,body,cta
HPT085_VID_Test Zap_1Bd-Z3_VeRelief Prime_AI VO_Multi_NA_New_Mark_JM_082726,hook1.mp4,body.mp4,cta.mp4
...
```

```bash
python3 scripts/assemble.py jobs/HPT085.csv --media ~/Drive/HPT085 --out exports/HPT085
```

- Clips can come from anywhere: mixed sizes, frame rates, and silent clips are all fine.
  Everything is conformed to 1080 wide, 30 fps, 48 kHz stereo.
- `--format 9x16,4x5` builds both aspect ratios. Each format goes in its own subfolder
  (`exports/HPT085/9x16/…`).
- `--fit pad` letterboxes instead of cropping, so nothing gets cut off when the source is a
  different shape.
- Cuts that already exist are skipped. Use `--force` to rebuild them, or `--dry-run` to see
  the ffmpeg commands without running them.
- Any column after `filename` is a clip, so `hook,body1,body2,cta` works too.

### `scripts/qc.py` checks exports before upload

```bash
python3 scripts/qc.py exports/HPT085
```

Fails a cut if any of these is true:

- The name's Creative ID, `VID` or variant token is wrong. The Winner Crawl matches live ads
  to briefs on those fields, so getting them wrong means a winning cut never gets tagged.
- The date lost its leading zero (`_82926`). Older briefs' shorter names (`…_1B_…`) pass
  with a warning.
- The frame isn't 1080×1920, 1080×1350 or 1080×1080.
- The video isn't H.264 / yuv420p.
- There's no audio.
- The file is over 4 GB.

Add `--max-seconds 30` to cap the length. It works on any export, not just `assemble.py`'s.

## Layout

| Path | What |
|---|---|
| `specs/meta-export.md` | Frame sizes, codec settings, safe zones |
| `jobs/` | Cut lists, one CSV per brief |
| `scripts/` | `assemble.py`, `qc.py` |
| `media/`, `exports/` | Local working folders, ignored by git |
